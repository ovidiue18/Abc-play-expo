1. Ce este AstravexOS
AstravexOS este o variantă modificată („modded") a Windows 11 Pro, construită pe imaginea oficială
Microsoft și apoi curățată de componentele considerate inutile. Nu este un produs oficial Microsoft și nu este
licențiat de Microsoft.
Ideea din spatele proiectului: o instalare de Windows 11 fără bloatware, cu servicii și procese de fundal
reduse la minim, optimizată pentru jocuri, streaming și PC-uri modeste — RAM puțin, HDD lent sau
procesoare vechi care nu trec de cerințele oficiale de Windows 11.
Rezultatul este un Windows 11 care:
pornește mai repede (raportări ale utilizatorilor: 30–50% mai rapid la boot);
consumă mai puțin RAM și are mai puține procese în idle (în mașină virtuală: câteva zeci de procese, față
de 150–200 pe Windows-ul standard);
ocupă mai puțin spațiu pe disc (compresie Compact OS + LZX);
are telemetria și aplicațiile preinstalate eliminate;
rămâne actualizabil prin Windows Update — nu este înghețat pe o versiune.
Se distribuie ca ISO de ~5,2–5,4 GB, în limba engleză (en-US), arhitectură x64, împachetat într-o arhivă
7z/RAR protejată cu parolă (25h2 sau 24h2, după versiune).
Pe scurt: același nucleu Windows 11, aceleași drivere și același Windows Update — dar cu stratul de aplicații,
servicii și telemetrie redus la esențial, plus un set de tweak-uri de performanță și un toolbox de configurare.

9. Instalare pas cu pas
Descarcă arhiva din sursa proiectului și verifică hash-ul (MD5 / SHA-256).
Extrage ISO-ul cu 7-Zip sau WinRAR (parolă 25h2 / 24h2).
Scrie ISO-ul pe USB cu Rufus (schemă GPT / UEFI, sistem de fișiere NTFS), cu WinNTsetup din mediul
WPE, sau cu Ventoy (simplu copy-paste pe stick).
Boot din USB — tasta de boot rapid (F12 / F11 / F8 / Esc) la pornire. Dezactivează Secure Boot dacă
întâmpini probleme.
În Windows Setup alege ediția dorită (COMPACT / SUPERLITE / SE, ±DEF), partiția, limba și contul de
utilizator.
După prima pornire deschide Astravex Toolbox și configurează: Store, Xbox, OneDrive, Print Spooler,
limba, AdminFilter.
Instalează driverele oficiale ale producătorului (GPU, chipset etc.), apoi antivirus dacă ai ales versiunea
fără Defender.

10. Actualizare și mentenanță
Windows Update funcționează — poți primi update-uri cumulative oficiale Microsoft.
Poți amâna update-urile până în 2077 (tweak inclus) — util pe termen scurt, dar nu recomandat:
rămâi fără patch-uri de securitate.
Fiecare „Update n" al proiectului aduce un ISO nou; nu este obligatoriu să reinstalezi — poți aplica
update-urile prin Windows Update sau face upgrade in-place.
Defender se poate reactiva din Toolbox doar în edițiile care îl conțin (DEF).
Păstrează ISO-ul curent pentru rollback: WinSxS fiind eliminat, dezinstalarea update-urilor nu este
posibilă.
11. Avantaje și dezavantaje
Avantaje
boot rapid, sistem „slim", consum redus de RAM și CPU;
instalabil pe hardware neacceptat oficial (fără TPM, CPU vechi);
zero bloatware, telemetrie redusă, confidențialitate mai bună;
Toolbox foarte practic: Store, Xbox, OneDrive, limbi, drivere, tweak-uri;
rămâne updatabil și suportă upgrade fără pierdere de date;
potrivit pentru gaming, streaming, mini-PC, laptop vechi, mașini virtuale.
Dezavantaje și riscuri
nu este oficial și nu este licențiat de Microsoft — statut legal ambiguu; activarea se face de
obicei prin soluții neoficiale (KMS / activatori), ceea ce încalcă termenii de licențiere;
securitate redusă în versiunile fără Defender: fără antivirus, fără SmartScreen;
WinSxS eliminat → nu poți dezinstala update-uri, repararea sistemului e limitată, unele feature-uri
opționale pot eșua;
posibile probleme de compatibilitate: imprimante, VPN corporate, RDP, jocuri cu anti-cheat
strict;
risc de ISO modificat dacă nu descarci din sursa proiectului;
fără suport tehnic oficial — doar comunitate;
în mediu de firmă sau producție: de evitat — probleme de conformitate, audit și securitate.

14. Concluzie
AstravexOS este o variantă „lite" de Windows 11 Pro: un sistem rapid, curat, fără bloatware și telemetrie,
instalabil pe hardware vechi. În forma actuală — 25H2 build
26200.9711 și 24H2 build 26100.9711 — este activ întreținut și updatabil.
Compromisul este clar: câștigi performanță și spațiu, pierzi securitate, suport și certitudinea
legală. Pentru gaming și PC-uri secundare este o opțiune populară și funcțională; pentru muncă, date
importante sau mediu de firmă, Windows 11 oficial (sau LTSC oficial) rămâne alegerea corectă.
